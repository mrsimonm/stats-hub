# Statistics Hub (4ST601)

A static, no-build study web app for **VŠE Prague 4ST601 (Statistics)**: step-by-step lessons, 4-star Mastery, flashcards, mini-games, mock tests, review, and a searchable dictionary.

- Run locally: `python3 -m http.server 8000` → open `http://localhost:8000`
- Validate data: `node tools/validate.js`
- Add a lecture: see `AUTHORING.md` and `PROMPT.md`
