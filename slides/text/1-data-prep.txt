*1) /singular/ the science of data, which
involves collecting, organizing, summarizing and
analyzing information
*2) /plural/ facts or data (either numerical and
non-numerical) organized and summarized so as
to provide useful information about a particular
object (element), event or process
*synonyms: measures, characteristics, …

=== SLIDE 12 ===
*Mathematical statistics: development, derivation and proofs of
statistical theorems, formulas and rules
*Applied statistics:
*Descriptive statistics /singular/ – methods
for organizing and summarizing information
(with the use of tables, graphs and simple
measures); the aim is to describe properties
of a data set; no generalization!
*Inferential statistics /singular/ – the aim is to draw
general conclusions about the population based on
information obtained from a random sample (data set)

=== SLIDE 13 ===
*Observation: each individual piece of data
*Data set: collection of observations (data),
usually presented in tabular form, where
each row represents a statistical element and
each column represents a statistical variable
*Statistical element: generally any object;
e.g. person, town, firm, etc. …
*Data set size (n): number of statistical
elements in a data set

=== SLIDE 17 ===
*Quantitative: its values are numbers resulting
from counts or measurements
*Discrete– its possible values form a countable set (most
often finite, theoretically also countably infinite;
typically only integer numbers)
*for humans, e.g. number of siblings, number of children, …
*Continuous– its possible values form some interval of
numbers; may have any value within a certain range;
number of its possible values is infinite
*for humans, e.g. height, monthly salary, …
17
=== SLIDE 18 ===
*Qualitative: its “values” (levels, categories,
classes) are expressible in words; they yield
non-numerical information
*may be used to subdivide the whole data set
into categories (groups); sometimes called
categorical variable
*for humans, e.g. eye colour, level of education, …

=== SLIDE 27 ===
*in the case of a low number of distinct values, each
of these values represents one class; we first group
the observations into classes (categories, bins)
*in the case of a high number of distinct values, we
group the observations into class limits; each class
consists of a range of values, i.e. an interval
including all values that fall within lower and upper
limit of the class
*Limit grouping: e.g. 30-39, 40-49, 50-59, …
*similar to class limits are class cutpoints
*Cutpoint grouping: e.g. 30-under 40, 40-under 50, …

the cumulative frequency calculated
*Choosing the number of class limits (i.e. intervals)

subjective; there’s no strict rule
*the aim is to get information about the (shape of)
distribution in the analyzed data set
