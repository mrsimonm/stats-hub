## Summary

Statistics lecture on descriptive correlation and regression analysis: Pearson's correlation coefficient, regression line by least squares, residuals, R squared vs adjusted R squared, and cautions with small data sets.

### Deterministic vs Statistical Relationships
- Deterministic: one variable's value fixes the other (dropped marker always falls); statistical: one value can lead to several outcomes.
- Correlation studies mutual relationships; variables have no special roles, so X and Y labels do not matter.
- Regression studies one-way relationships: X is explanatory/independent (cause), Y is dependent/response (consequence).
- Correlation measures only strength and direction of linear relationships; regression functions can capture other shapes.

### Correlation Analysis
- Pearson's correlation coefficient (transcribed 'Peasam's') ranges from -1 to +1 and needs only five arithmetic means.
    - Numerator is the covariance; denominator is the product of two standard deviations
- r = 0 means linear independence only, not full independence; nonlinear patterns can still exist.
- Always pair a correlation coefficient with a scatter plot, especially for small data sets (four plots all with r = 0.81).
- Student data set (165 students): age vs semester r = +0.46 (intermediate positive), F grades vs semester r = 0.3 (weak positive).
    - Age vs weight showed weak positive correlation, explained by more men among older students; near 0 when split by sex

### Regression Functions and Classification
- Three functions covered: regression line (p = 2), quadratic function (p = 3, regressors X and X squared), regression plane (p = 3, two explanatory variables).
- Parameters B0, B1 differ completely between functions despite shared notation.
- Quadratic function is simple regression factually but multiple regression mathematically (two regressors).

### Regression Line Example (9 Male Students, 2014)
- Fitted line: weight = 56.13 + 0.774 x age, derived via least squares (transcribed 'method of P squared').
- Slope interpretation must be descriptive, not causal: a student 1 year older typically weighs 0.774 kg more.
    - Causal interpretation to be discussed in lecture 11
- Prediction for age 23 gives 73.93 kg; predict only near the data range (ages 18 to 26).
- Residuals = observed minus fitted; least squares minimizes error sum of squares, here 459.48.

### Goodness of Fit and Exam Notes
- SST = SSR + SSE; R squared = SSR/SST, here 0.065 (line explains 6.5% of weight variation).
- R squared rises with more regressors, so compare functions with adjusted R squared, which has no factual interpretation.
    - Adjusted R squared: line -0.068 vs quadratic -0.21, so line fits slightly better
- Quadratic and plane parameters are Excel-only; exam may give them and ask follow-up calculations and partial parameter interpretation.
- Removing the 26-year-old flips the slope to negative, showing small data set fragility.
